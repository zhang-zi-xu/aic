## 方法与口径

- 检索为**可控关键词加权 + 元数据过滤**（标题 10 > 关键词 8 > 作物 5 > 正文 3；2-gram 召回 + 同义词扩展），**未使用向量检索**。
- 硬约束：作物不符的片段一律不召回；地区按层级匹配（浙江 ⊂ 长江中下游、河南 ⊂ 黄淮，全国性资料始终可用）。
- 质量约束：必须至少有一个检索词命中**标题/关键词/作物**，仅靠正文偶然命中（如"病防"）不算依据；泛化 2-gram（防治、管理、技术等）在检索前剔除。
- 每条用例的"可接受来源"由人工对照原文确认（同一问题可能有多条合格来源，例如河南本地意见与全国方案都覆盖赤霉病）。

## 已知局限

- 只摘录了与问答相关的段落，**未收录全文**；需要完整表述时请打开原文链接。
- 覆盖范围仅两类作物、两个地区；其它作物/地区会检索不到依据，此时系统应回答"没有查到可引用的依据"。
- 关键词检索对同义表述的召回有限（例如方言或错别字），准确率数字仅对应上表 15 条用例，不代表全部问题。
- 农药登记与剂量不在资料库结论范围内，系统一律输出核查步骤。

## 与 README 混合检索评测的口径区别

本表的 **15/15 = 100%** 是**术语型提问**（"稻瘟病 破口前""小麦蚜虫 百穗蚜量"）下的关键词检索结果——这类提问的字面词就落在资料里，关键词路几乎必中。

README 中"关键词 Top3 命中率 25% → 三路混合 91.7%"是**口语化提问**评估集（"叶子像被开水烫过一样发白枯萎""稻丛基部一层小白虫"）的结果——这类提问不含术语，关键词路基本失效，靠向量/图谱路补召回；该数字在本地哈希向量模式下测得。

两者样本不同、提问风格不同，**不能互相替代**：报告检索质量时必须写明是哪一种提问方式下的数字，也不要把其中任一个当作整体检索能力。
