## 五、硬约束与已知陷阱（务必遵守）

- **密钥**只走环境变量（`NONGXIN_TEST_KEY` 等），不写文件/不落库/不落日志；提交前必查 `sk-` 痕迹
- **冻结声明**（路线图 §2.7）：不再改提示词与兜底逻辑；已知取舍"方案卡出现率 1/4"待真实反馈裁决
- **写非 ASCII 源文件不要用 `Set-Content`**（会用 ANSI 写坏）；PowerShell 脚本要么**纯 ASCII**、要么存成**带 BOM 的 UTF-8**（PS 5.1 否则按 GBK 读，中文注释会引发语法错误）
- 政府网站编码不统一：先读 charset 声明，再 UTF-8，最后 GB18030（已在采集脚本里处理）
- 打包前**必须先停掉 8080 的 java 进程**（否则 jar 被锁）；`mvn` 必须在 `D:\aic\server` 下执行
- 命令速查：后端测试 `mvn -o test`（workdir `server`）；前端 `npm test`；打包 `mvn -o -q package -DskipTests`
